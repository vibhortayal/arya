# 2026-10-29 — First-run experience (#153, #163)

Built the owner-approved mockup (welcome, tour, Get started, Lists first
card, Settings replay row) in the React app. Branch `feat/first-run`;
no PR yet.

## What changed
- **Server (`api/routes/account.py`).** `GET /api/settings` now also
  returns `onboarded` and `get_started`. The flag lives in the
  per-account `settings.json` (same store as `language`), so it holds
  across devices. Rule: an account is onboarded if it has the flag OR
  holds any named list, any item flag, any receipt (own or group) or any
  Quest session. The demo household is always onboarded and never gets
  the card. `POST /api/settings {"onboarded": true}` sets the flag; only
  an account that is still empty at that moment gets `get_started`.
  `{"get_started_dismissed": true}` closes the card. When all three
  steps are done (a named list or a manual item; a tracked expiry date;
  a receipt) the server ends the card for good.
- **Welcome sheet (`ui/FirstRun.tsx`).** Shown by the Shell when the
  session says `onboarded === false` (never for the demo, never while
  settings load). Show me around and Skip for now (and a scrim tap or
  Esc) all mark the account onboarded.
- **Tour (`ui/Tour.tsx`, `onboarding/firstRunTour.ts`).** Reusable:
  steps are data (`id`, `target` selector or function, `titleKey`,
  `bodyKey`, `onEnter`, `placement`), started with
  `useTour().startTour(steps, { onDone, onSkip })`. Hole by box-shadow,
  bubble above or below to fit, target scrolled into view, layout follows
  resize and scroll, Esc and Skip close, focus on Next, reduced motion
  turns off the movement. Documented in `web/PORTING.md`.
- **Today.** A Get started card (kicker "N of 3", three steps with real
  done states, a small × to close). While it shows, the empty Use soon
  snap row, the Did you know? tip, and (with no lists) the Quest row are
  hidden. Steps open the new-list sheet on Lists, the expiry snap sheet,
  and the Receipts screen.
- **Lists.** With no named lists, no items and no suggestions: one card
  (basket, title, line, "Create your first list"). The title and line
  can be dropped with `EMPTY_CARD_TEXT = false` in `Lists.tsx`.
- **Settings.** "Show me around again" between Stores and Arya's powers.
