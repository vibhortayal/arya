## Stage 2 — Collect celebration (Discussion 32)

- **Characters (Muse Image, 20 images, $0.20 total).** New
  `MetaClient.generate_image()` door in api/meta_client.py
  (POST /v1/images/generations, $0.01/image, ledger-recorded;
  the API returns no usage block for images — spend is the flat
  per-image price). Generated by tools/gen_characters.py through
  the connector surrogate, one style prompt for all: cute flat
  mascot, big friendly eyes, simple bold shapes, soft colors,
  plain light cream background, no text. Files (WebP, 45–107 KB)
  in pwa/assets/characters/: blueberry, banana, raspberry,
  mandarin, egg, cheese, bread, pasta, pizza, hummus, olive-oil,
  peanut-butter, almond, milk (items) + fruit, vegetable, dairy,
  bakery, frozen, pantry (category fallbacks). Spot-checked:
  on-style, no text in image.
- **Manifest** (assets/characters/manifest.json): keyword rules —
  exact item first, then category; character and fact resolve
  independently (strawberry: own fact, fruit character; milk: own
  character, dairy fact). Facts are the brief's verified bank,
  verbatim — fun facts only, no nutrition/health claims; the
  vegetable category is character-only, no fact. Tests pin every
  fact string against the bank.
- **Behavior.** qOnCollected is the single hook: GRAB, marker
  taps, Shelf Scan pops — and panel checks, which did NOT route
  through it in code (the stage brief said they did); the panel
  handler now fires it when a check turns an item collected.
  Quest mode only (Q.current.mode gate — Express never fires);
  fires after state is recorded, so it never delays a collect;
  "Not here" never calls it. The celebration is a non-blocking
  layer (#celeb-layer) over the hunt scene: character pops with a
  CSS bounce, fact in a speech bubble, auto-dismiss 3.5 s or on
  tap; a rapid collect replaces the bubble (one timer, never
  stacked); prefers-reduced-motion gets a fade. The manifest is
  warmed at openHunt. SW cache bumped to arya-v24 with the
  manifest + all 20 characters precached (pins updated in
  test_brain_restyle, test_motion_nav, test_stores).
- **Tests:** tests/test_celebration.py (7) — manifest facts
