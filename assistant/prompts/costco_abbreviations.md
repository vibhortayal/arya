# Costco receipt abbreviation hints (shared by every Costco decode path)
Hints, not facts: use them to read a printed name, never to invent one. If a
line still does not fit, say so with a low confidence and give alternatives.

- KS = Kirkland Signature (Costco's own brand). KS before a product is the brand.
- ORG = organic. NAT = natural. UNSLTD / UNSLT = unsalted. LF = low fat. FF = fat free.
- BL = blue / blueberry (food) or bed-and-bath brand prefix (non-food): decide from the rest of the line.
- BLUES = blueberries. STRWBRY / STRAWB = strawberries. RASP = raspberries.
- 3PC, 6PC, 12PK, 24PK = pieces / pack count. CT = count. LB = pound. OZ = ounce. GAL = gallon.
- KING / QUEEN / TWIN / FULL after a count of pieces = bed size for a sheet or bedding set.
- SHT / SHTS = sheet(s). TWL = towel. TP = toilet paper. PT = paper towels. BATH TISS = bath tissue.
- CHKN / CHK = chicken. BRST = breast. THGH = thigh. GRND = ground. BNLS = boneless. SKNLS = skinless.
- BNLS SKNLS CHKN BRST = boneless skinless chicken breast.
- MOZZ = mozzarella. PARM = parmesan. CHED = cheddar. YOG / YGRT = yogurt.
- ALMD / ALMOND MLK = almond milk. EVOO = extra virgin olive oil.
- Items like TV, laptop, tire and vitamin lines often print a model number: keep the brand and model words.
