## receipts | receipt receipts photo pdf scan total return refund recall add history
Receipts: open the Lists tab, scroll to the bottom and tap Receipts, or tap Add receipt after a trip. You can take a photo, pick one or many PDFs or photos at once, paste order text or say it.
Arya reads the receipt and checks the total. It keeps every receipt for a return or recall refund.

When some receipts cannot be read, Arya lists each file with the reason under the Add receipts button. If Arya's reading is paused or the daily limit is reached, it stops after the first file instead of trying them all; try again later.
In Receipts, a To check row opens its own screen. There, To check shows one card per product, even when it appears on several receipts (the card says how many, for example ×5). Find a receipt: in Receipts, under Archive, type a store or an amount in the search box. A return is taken off the spending. Only you and your group see your receipts.
Lines Arya is unsure about are under the To check row in Receipts, which opens the list. Each card leads with Arya's guess (or "Arya's guess · not sure"), then what was printed, the store, price and a section tag such as Dairy & eggs. Tap Use this name to take the guess, Fix to change the name or section (it opens with the guess filled in), or Keep printed to keep the name as printed. A card Arya could not read says so and offers Type the name. While Arya is still reading new lines, their cards say "Arya is reading this name". Details shows what you paid, where, when, how it was printed, the item number and how sure Arya is. At the top, Use the N sure guesses sets every guess Arya is sure of (85% or more) in one tap; one Undo on the message puts them all back. Unsure guesses are never set without you.
Costco names like "BL 3PC KING" are short codes. Arya tries to read them, using known Costco abbreviations, and never looks anything up on store sites. If it is not sure, the line goes to Review with its best guesses; rename it once and Arya remembers that item.
Clean names: Arya turns printed names into list names, product first, for example "ORG BLACKBRY" becomes "Blackberries - Organic", and reuses the name for that item number. Receipts, prices and totals are not changed. A name it is not sure of waits in To check and is not suggested until you answer. A name you set always wins.
