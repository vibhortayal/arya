Arya Quest — UX

Click a screen to jump, or tap through inside the phone — the buttons work. Greyscale is structure; the orange is the game. Screen 0 is the signed-out Landing; screens 1–16 are Quest; B1–B5 are the Brain (B6 lives inside Profile, screen 12).

    Start at Landing (the judge's front door). Try the fixed path: Today → Resume Trader Joe's → in the Hunt, GRAB Sourdough (stop 5) before Organic Milk, then tap ↩ Put back on Milk's row — the row never moves, nothing closes, the count just changes. Collect everything (the hunt waits — no auto-finish) → Finish → → Skip receipt → Score reads “hunt finished” → back on Today the hero is gone and the quest sits once under Finished · Receipt missing → tap Add receipt (its own screen — not Finish) → Back returns you to Today, exactly where you tapped it.

    One app — Arya

    ⇄

    Arya Quest — the play layer

    Hunt & collect in Quest · fastest route in Express · Shop-Off races. Sessions sit on the same Today hub — the hero card and the game rows under it.

    One loop closes both: hunt ends → receipt snaps → haul verified for the game and fed to the brain, so next week’s list starts itself. One hub · one account · one receipt.

    Navigation: one bottom bar — Today / List / Add / Ask / Profile. Quests live on Today, not in a tab. Back is a stack: it always returns to the screen you came from — Finish → the hunt, Receipt detail → Receipts or Profile (wherever you opened it), Add receipt → wherever its button was tapped. Never a hard-coded Home. A finished hunt closes: it leaves the Today hero, and adding its receipt later is a Receipts job on its own screen — it never reopens the hunt. Spend lives in Analysis (Profile → Analysis), aggregated from receipts — never on Today.
