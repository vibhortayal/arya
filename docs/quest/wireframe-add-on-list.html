Decisions in this wireframe

  1. The Add tab is removed; the bottom bar is Today · List · Ask · Profile.
  2. One composer on List: type/paste in the field, mic and camera as icon buttons — the Add tab's three doors, one row.
  3. Paste splits are shown as chips before adding; a single item still adds on Enter, instantly.
  4. Eyes confirmations sit under the composer, only when pending.
  5. The “Every door runs on Meta models” line becomes footer small print on List.
  6. No server change: the composer calls the same from-text / transcribe / from-photo doors the Add tab calls today.
